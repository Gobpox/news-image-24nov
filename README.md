# The World in One Picture — Tuesday 24 November 2026

A make.fun `news-image-20261124` entry: one 1024×1024 image summing up
Tuesday 24 November 2026's world news.

## Build

`draw.py` renders `entry.png` with Pillow from a single story data table.
Figures live in `figures.json`, the single registry every panel draws
its numbers from. `main.py` is the competition entry point: it copies
`entry.png` to the output directory, standard library only,
deterministic bytes.
